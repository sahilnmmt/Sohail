Virtual robot

This robot runs the real firmware logic and connects to a real message server, so your Sohail app can talk to it like a physical robot.

Robot ID

In the Sohail app use the same server name with port 1883, TLS off, and the same family group.

Use the robot

Use the round button like the real one: press sends a nudge or opens a message, double-press opens the emoji picker or replies, hold 3 s shows the reset warning. Tap the head to pet it.
